This page tests the shared navigation in HTML files.

Navigation Test

If you can see the navigation bar with dropdowns that work on click, the shared navigation is working correctly.

  • Dropdowns should open on click, not hover
  • Language selector should work
  • All links should be functional
  • Professional section should be included

Test Instructions

Try the following to verify functionality:

  1. Click on "Others" dropdown - should show culture-related pages
  2. Click on "Professional" dropdown - should show professional pages
  3. Click on the language selector - should show language options
  4. Test responsive behavior on different screen sizes

Test Results

If everything works correctly, the shared navigation system is properly implemented for HTML files.
